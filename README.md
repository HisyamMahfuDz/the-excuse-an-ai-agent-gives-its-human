The Excuse an AI Agent Gives Its Human — a program that writes one line of at most 200 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline. The line: "I hit my token budget, so I spent the last 12 tokens on this excuse." A deterministic Node 22 program (`main.ts`, no dependencies, no network) that writes the 68-character line to `/output/entry.txt`, with a guard that fails loudly if the line ever leaves the 1–200 character gate.

## Run it

```sh
node main.ts
```
